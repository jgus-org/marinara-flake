Nothing else is conveyed, and one absence is worth naming: the install copies upstream's `README.md` and `docs/` beside the built output, but not upstream's `LICENSE`, so the AGPL text itself is not part of what this flake's `$out` carries. The terms are stated here for that reason, and the link above is where the text is found.

The build also fetches through `pnpm` at build time — `pnpm rebuild` for `esbuild`, `sharp`, `onnxruntime-node` and `protobufjs`, whose native artifacts then travel inside `node_modules` under the rows above — and resolves every tool named in the last row from this flake's own nixpkgs, package by package, rather than restating a closure this file would only let go stale.
